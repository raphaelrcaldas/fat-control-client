Erro de validação (422) nunca é genérico

O backend devolve ApiErrorResponse.errors como campo → mensagem. Exibir só o message de topo entrega um "Erro de validação" inútil. Cada erro volta ao seu input por setError do react-hook-form, além do resumo no toast. Campo opcional em branco viaja como null, nunca "".
