A mesma marcação, outra organização. Os utilitários *-primary-* e os componentes Flowbite leem --primary-50..900, que é só um alias para uma escala do Tailwind. O atributo data-org-theme no <html> — gravado por cookie no SSR — decide para qual. Trocar de organização não toca em nenhuma classe.

Espelha o TemaEnum do backend (fcontrol_api/enums/tema.py) — manter os dois em sincronia. Sem cookie de organização (primeira carga, aba anônima, relogin) o padrão é slate neutro, não red.

Reserva semântica

primary-*
Marca da organização ativa. Ação primária, espinha do Masthead, caixa de ícone, estado ativo de paginação.
red-*
Perigo, exclusão e erro — só isso. Vermelho cravado num módulo antigo é legado da migração de tema: migrar para primary-*.
slate-*
Chrome neutro e telas de admin de sistema (cross-tenant). Ali não cabe primary-*, que é a marca de uma organização.
